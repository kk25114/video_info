# 抖音 Playwright 发布脚本指南

## 使用示例（推荐）
```bash
bash /home/github/video_info/publish_latest.sh
```
脚本会自动挑选 `/home/github/video_info/mk_video` 下最新的 `.mp4`，生成最新文稿简介与话题并发布，完成后在 `test/latest.png` 留存截图。

## 1️⃣ 环境准备
- 推荐使用 Conda 创建隔离环境：`conda create -n douyin-playwright python=3.10`，随后 `conda activate douyin-playwright`
- 安装依赖：`pip install -r requirements.txt`
- 安装浏览器内核（首次执行）：`playwright install chromium`
- 保障网络可访问抖音创作者中心，避免代理频繁切换触发风控

## 2️⃣ 登录并保存会话
- 执行：`python3 scripts/login_and_save_state.py --state-path storage_state.json`
- 浏览器会打开上传页面，扫码/账号登录至可看到上传入口
- 登录完成后返回终端按回车，脚本会保存 `storage_state.json`
- 如需长期保持登录，可追加 `--user-data-dir cookies/creator` 复用本地用户目录

## 3️⃣ 发布视频流程
- 准备视频与标题，例如：`素材/示例视频.mp4`
- 执行：
  ```bash
  python3 /home/github/video_info/douyin_playwright/scripts/publish_video.py \
    --video /home/github/video_info/mk_video/videos/video21.720p.mp4 \
    --auto-desc \
    --state-path /home/github/video_info/douyin_playwright/storage_state.json \
    --wait-upload-text "上传成功" \
    --publish-selector 'button.button-dhlUZE.primary-cECiOJ.fixed-J9O8Yw' \
    --success-text "发布成功" \
    --slow-mo 200 \
    --screenshot /home/github/video_info/douyin_playwright/test/latest.png
  ```
- 脚本会自动上传、填写标题并点击发布，可根据页面实际结构调整参数
- 若页面存在确认弹窗或自定义按钮，可通过 `--confirm-selector`、`--publish-selector` 等参数覆盖

## 4️⃣ 选择器与稳健性建议
- 默认选择器为经验值，若页面改版请使用浏览器开发者工具复制准确的 CSS 选择器
- 常用待覆盖选项：
  - `--file-input-selector`：文件上传 input，例如 `input[type="file"]`
  - `--title-selector`：作品标题 textarea（如需填写标题时再使用）
  - `--desc-selector`：作品简介输入区域（在未启用 `--auto-desc` 时可手工指定）
  - `--publish-selector`：发布按钮，可与 `--publish-fallback-selectors` 组合使用，例如 `'button.button-dhlUZE.primary-cECiOJ.fixed-J9O8Yw'`
  - `--success-selector`：发布成功提示框容器，例如 `.success-toast`
- 可在 `config/` 目录中自建 JSON/YAML 文件记录团队约定的选择器与参数
- 若默认 `textarea` 不适配，可通过 `--title-fallback-selectors 'div[contenteditable="true"]'` 等参数补充候选
- 若简介输入框较难匹配，可使用 `--desc-fallback-selectors 'div[contenteditable="true"]::nth=1'` 等参数指定
- 如需留存执行现场，可追加 `--screenshot test/latest.png` 保存页面截图
- 新增自动处理地理位置授权、页面弹窗与上传进度等待逻辑；如仍提示“允许访问位置”，可在命令中追加 `--headless` 关闭无窗口运行或手动点击

## 5️⃣ 常见问题处理
- **登录态失效**：重新运行登录脚本保存最新 `storage_state.json`
- **人机校验**：关闭无头模式（默认已关闭），操作减速或人工介入；必要时加入 `--slow-mo 300`
- **上传超时**：增大 `--upload-timeout`，并通过 `--wait-upload-selector` 精确等待进度条完成
- **发布按钮无响应**：确认右侧提示已显示“上传成功”，并指定 `--publish-selector` 为真实按钮（如 `'button.button-dhlUZE.primary-cECiOJ.fixed-J9O8Yw'`）；若弹出“我知道了/放弃”等提示，需先关闭弹窗
- **批量发布**：结合任务清单脚本或 Cron，循环调用发布脚本并记录成功/失败日志

## 6️⃣ 安全与合规提示
- 遵守抖音平台服务条款，控制发布频率与内容质量
- 保存的 `storage_state.json` 含登录敏感信息，请妥善存放并加入版本忽略
- 建议在内网环境运行自动化任务，必要时叠加企业级代理和风控策略
