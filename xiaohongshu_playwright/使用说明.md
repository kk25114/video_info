# Windows 10 小红书自动发布

`publish_latest.ps1` 是 Windows 原生入口。它会优先从旧 WSL 输出目录
`D:\Program Files\下载` 选择最新的 MP4；该目录不存在时，改从当前用户的
`Downloads` 选择。也可以用 `-Video` 或 `-VideoDir` 明确指定素材。

脚本默认使用 Windows Chrome 的真实用户配置：
`%LOCALAPPDATA%\Google\Chrome\User Data\Default`。因此你平时已经登录的小红书
会直接生效，不需要把抖音的 Cookie 或 WSL 登录态复制过来。运行前请关闭所有
Chrome 窗口，否则 Chrome 的配置锁可能阻止 Playwright 启动；发布结束后脚本会
自动关闭它启动的浏览器窗口。若使用 Chrome 的其他配置，可通过
`-ChromeProfileDirectory "Profile 1"` 指定。

## 首次配置

在 Windows PowerShell 中进入仓库根目录，安装发布器依赖（电脑上需要已安装
Chrome 或 Edge）：

```powershell
py -3 -m pip install -r .\xiaohongshu_playwright\requirements.txt
```

## 已登录时直接发布

确认 Windows Chrome 中已经登录小红书，关闭全部 Chrome 窗口后运行：

```powershell
.\publish_latest.ps1
```

脚本会打开小红书官方创作服务平台，上传最新 MP4，填写标题和正文，并自动点击
“发布”。默认只使用 Chrome 用户配置，不会另存 Cookie；如需额外生成 Playwright
登录态备份，再加 `-SaveState`。仓库内的备份文件和备用资料目录已被 Git 忽略；
真实 Chrome 配置位于仓库外，不要复制、提交或共享其中的账号数据。

如果 PowerShell 阻止执行脚本，可只对当前窗口放行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

也可以双击或在命令提示符中运行 `publish_latest.cmd`。

## 首次登录或更换账号

若 Chrome 尚未登录，先关闭全部 Chrome 窗口，再运行下面的备用脚本；在打开的
浏览器中手动登录后回车保存：

```powershell
py -3 .\xiaohongshu_playwright\login_and_save_state.py
```

如果你使用的不是 `Default` 配置，可以这样指定：

```powershell
py -3 .\xiaohongshu_playwright\login_and_save_state.py `
  --profile-directory "Profile 1"
```

## 发布

```powershell
.\publish_latest.ps1
```

默认会从最新文稿生成标题、正文与话题，因此需要在环境变量 `DEEPSEEK_API_KEY`
或根目录 `config.json` 中配置自己的 Key。若想使用视频文件名或手工文案：

```powershell
.\publish_latest.ps1 -NoAutoDesc -Title "我的标题" -Description "正文内容 #话题"
```

常用命令：

```powershell
# 只检查上传和文案填充，不点击发布
.\publish_latest.ps1 -NoPublish

# 在自动点击发布前停下来检查页面
.\publish_latest.ps1 -PauseBeforePublish

# 可选：把当前登录态另存为 Playwright storage_state.json
.\publish_latest.ps1 -SaveState

# 指定视频或视频目录
.\publish_latest.ps1 -Video "D:\素材\成片.mp4"
.\publish_latest.ps1 -VideoDir "D:\素材"

# Chrome 使用其他 User Data 根目录/配置
.\publish_latest.ps1 -ChromeUserDataDir "$env:LOCALAPPDATA\Google\Chrome\User Data" `
  -ChromeProfileDirectory "Profile 1"
```

若登录态过期，重新在 Chrome 中登录或运行登录脚本。若页面出现人机验证、内容审核
提示或平台改版，请在浏览器中手动处理；发布器不会尝试绕过这些步骤。发布成功或
失败都会将现场截图保存到 `xiaohongshu_playwright\test`。

Windows 入口只负责发布已有 MP4，不会调用 WSL 专用的 `mk_video/build.py`。需要
重新制作视频时，先在 WSL 完成构建，再从 Windows 的共享目录用 `-VideoDir` 发布。
